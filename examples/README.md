# Examples Directory

Scratch workspace: working copies of notebooks for learning and
experimentation. Nothing in here is gated by CI or published to the docs -
the maintained, executed tutorials live in docs/tutorials/.

- Files here are meant to be modified and experimented with; copy any
  notebook and break things freely.
- Some of these predate the 0.2.0 API rename (chart='Imr' -> 'X',
  paired= -> companion=) and will need touching up before they run.
